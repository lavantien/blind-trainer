# ref_doc layout and regeneration

ref_doc holds the offline grounding snapshots for the 3BLD trainer: `bld/` (speedsolving wiki raw wikitext for Speffz, List_of_letter_pairs, BLD_Memorization, blddb readmes for both branches) and `vietnamese/` (Wikipedia phonology wikitext, the Kirby JIPA Hanoi Vietnamese paper, the vietnameselanguage/syllable wordlist, tabidots/vn-freqs word frequencies, and the KienTranOMRE/vietnamese-bigram-lm outputs). Every fetched file starts with 3 lines prefixed by `# ` giving source URL, retrieval date, and license, so data consumers skip lines starting with `# `; the one pdf is saved bare with a sidecar `.meta.txt`. Regenerate the fetched snapshots with `python scripts/fetch_docs.py`, which rewrites `MANIFEST.md` with sha-256, byte size, path, and URL per file. The full directory is gitignored local grounding, except this README; see `DATA_PROVENANCE.md` at the repo root for license posture.
