# t41 e2e driver port (L21)

## scope

port tests/e2e/src/main.rs (bt-e2e crate, 12 unit tests + smoke driver) to a c23 driver at tests/e2e, port the makefile e2e target surface into bt.py (e2e, e2e-smoke), and port the headless flow suite crates/bt-app/tests/e2e.rs to tests/unit/app/e2e_test.c per the t15 map row.

## status

- 2026-10-28: driver units landed. tests/e2e/{lib,proc,png}.{h,c} + main.c. lib.c carries config parsing (e2e settings, window dims, neg exit), out-dir resolution, png dir walk (wide crt), classify, check_shot (ihdr dims), tail. proc.c is the windows tu: CreateProcessW with pipes, two reader threads, 100 ms poll against a shared deadline, TerminateProcess on timeout, wide env block with CREATE_UNICODE_ENVIRONMENT. png.c validates signature + ihdr and reads big-endian dims. main.c mirrors real_main: smoke run over the real exe, found vs expected shot classification, per-shot dims check, summary line, negative-config leg expecting release.neg_config_exit, exit 0/1/2 with bt-e2e prefix.
- 2026-10-28: 12 driver tests at tests/unit/e2e/driver_test.c green through python bt.py test-unit e2e (red first: missing header, then return-code mismatches and a tail off-by-one fixed against the rust bodies). png fixtures are hand-built minimal pngs (3x2 and 2x2, generated with zlib, embedded as byte arrays).
- 2026-10-28: bt.py: compile_stage lets tests/e2e/ compile for the e2e test area, link_stage links bt-e2e.exe (all tests/e2e objects + common + vendor) and joins the non-main tests/e2e objects into e2e-area suite links. config build.e2e_exe names the exe.
- 2026-10-28: flow suite tests/unit/app/e2e_test.c (6 tests from crates/bt-app/tests/e2e.rs) green through python bt.py test-unit app --only e2e on first run: it transcribes behavior logic/persist lanes already landed, expected values taken from the rust bodies.

## bounds

- check_shot validates png signature + ihdr dims, not a full decode: a truncated idat with an intact header passes c and fails rust image::open. unreachable from the driver since raylib writes the shots; recorded as the c bound.
- io error suffixes on cannot read/remove paths are fixed strings without the os error text, the recorded genre for this port. messages the rust tests pinned are byte-exact.
- bt.py e2e/e2e-smoke build scoped (app + e2e areas), never the full tree, mutate.exe lock stays untouched.
