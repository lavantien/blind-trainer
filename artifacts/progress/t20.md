## Root causes found on the way

- last_run ledger buffer was 1 byte, bt_mut_now_iso wrote 19 bytes, heap
  corruption, fixed on both the upsert and load paths.
- CreateProcessW application name with forward slashes fails, links and spawns
  now pass a quoted backslash command line with a null application name.
- std flag must be the single token -std=c23 like bt.py, two tokens fail clang.
- clang -O2 deletes a side-effect-free infinite loop, the spin fixture keeps a
  volatile sink so a frozen loop stays observable and times out.
- the engine link list mirrors bt.py exactly: src objects, test object, gen
  main object, then the built vendor objects under the object root, the raw
  vendor source tree must never be scanned.
- directory scans feed entries relative to their scan base, a nonempty
  relative prefix double prefixed every path.

## Adversarial fix round

- spawn.c: deadline checked at the top of every loop iteration so a flooding
  child still times out, the child joins a job object with kill on close so the
  timeout takes the whole tree, captured output stops growing at 16 MiB,
  compile timeouts now return -2 distinct from spawn failures.
- buildcmd.c: compile argv appends -isystem <root>/vendor/sqlite after the
  three -I pairs, matching bt.py, pinned by the stub argv contract test.
- main.c: non-.c targets are rejected with a usage error naming the file,
  selftest-flood floods stdout for the flooding child selftest.
- prepare_scratch: only the parent of each copied input is created, dep tokens
  are backslash normalized and compared against a normalized repo root so
  headers actually land under inputs/, every write return is checked, the
  marker carries the owning pid.
- scratch.c: a slot whose marker pid is alive is never reclaimed, the creation
  age rule applies to dead owners only.
- engine.c: a spawn error during compile, link, or run leaves the row pending
  so a retry re-runs it, only real compile or link failures are builderr.
- ledger.c: 11th column test_exe, 10 column rows load with an empty test_exe,
  rows whose test_exe differs reset to pending, stale rows for re-enumerated
  files are dropped at run start, bt_mut_ledger_drop added.
- operators.c: numeric cores and suffixes are length bounded, statement_start
  resets on semicolon only outside parentheses and after a guard paren closes,
  literal-only BT_TRACE_ENTER EXIT FAIL calls are exempt from deletion while
  non-literal trace calls stay mutants, from and to reject tabs and newlines.
- gate lib.c: a leading minus in the count column is rejected, counters must
  be json integers so 1.0 or 0.0 no longer pass, merge writes integer
  counters, report.c writes integer counters and spans.
- Known constraint: ledger saves are atomic renames but a concurrent reader
  can still see the previous content mid run, the sequential pipeline contract
  is one mutate invocation per ledger at a time, recorded here as accepted.
- Selftests grew to mutate 26 and gate 42, both green on the final binaries,
  test-unit tools green, fmt, lint tools, check green.
