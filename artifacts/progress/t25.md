# t25 lane L5 ga crate port

Scope: port crates/bt-ga (features, inventory, ga, hash, dist, lib) to C23
under src/ga with tests under tests/unit/ga. Expected values come only from
the Rust test bodies. Rust stays untouched as reading material.

Baseline at lane start: ga area absent from bt.py, no src/ga, no tests/unit/ga.

## Step 1: red test surface

- Headers: src/ga/inventory.h, features.h, ga.h, hash.h, dist.h, lib.h.
  bt_ga_case_row and bt_ga_pair_count (dist) carry the freq data rows,
  bt_ga_case_count stays a function like Rust inventory CASE_COUNT.
- tests/unit/ga: ga_test_util.h (watchdog thread, scratch dirs, feat
  builders, wordlist helpers), death_test.h (env self-spawn, exit 134),
  features_test.c, features_tables_test.c, inventory_test.c,
  inventory_more_test.c, ga_test.c, ga_public_surface_test.c,
  fuzzkill_ga_test.c, hash_test.c, dist_test.c, lib_test.c.
- 105 tests total across 11 exes: 13 features, 3 features_tables, 14
  inventory, 6 inventory_more, 23 ga, 7 ga_public_surface, 22 fuzzkill_ga,
  2 hash, 2 dist, 1 lib, plus 12 watchdog/death helpers in the suites.
- Red state: every exe compiles, every link fails on undefined bt_ga_*
  symbols. Verified with python bt.py test-unit ga.

## Step 2: implementation to green

- src/ga/lib.c, hash.c (common sha256 wrapper), features.c (tone/rime
  tables generated by playground/ga_tables.py, parse with merged-gi rule,
  confusion and flow penalty), inventory.c (wordlist and frequency loaders,
  nucleus_rime, tone_char via the tone table, onset spellings, render,
  zero onset variants, inventory build with sort and adjacent dedup, pool
  build), ga.c (env tables, fitness, ox with linear kept-membership,
  cuts, mutations, tournament, run with elite aliasing and recomputed
  scores, config reader), dist.c (json freq data loader, eq, memofreq).
- bt_ga_build_env gained a table_count parameter so the Rust mismatch
  rejection stays testable in C, headers and all call sites updated.
- bt_ga_utf8_valid is public plumbing shared by both loaders.
- 8 of 10 exes green mid-step; ga_ga_test and ga_ga_public_surface_test
  pending a relink blocked by the concurrent t22 seedpack breakage in
  src/data/seedpack/normalizer.c (missing stdarg.h, not this lane's file).

## Step 3: close

- python bt.py test-unit ga: 10 exes, 105 tests, 10 passed 0 failed.
- python bt.py fmt: clean. python bt.py lint src/ga tests/unit/ga: 9 clean.
- python bt.py check src/ga: code 0.
- policy scan: the ga literals are centralized (BT_GA_ERR_MAX across dist,
  BT_GA_PARSE_MAX for the parse buffers) or allowlisted (63 utf-8 mask,
  1.0 identity confusions and flow units, 0.0 accumulation identity).
- Deviations: build_env carries an explicit table_count, exported internal
  helpers for tests, watchdog thread instead of a child process, rayon
  evaluation order kept sequential, common sha256 replaces the crate-local
  hash.rs implementation.
