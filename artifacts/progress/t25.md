# t25 lane L5 ga crate port

Scope: port crates/bt-ga (features, inventory, ga, hash, dist, lib) to C23
under src/ga with tests under tests/unit/ga. Expected values come only from
the Rust test bodies. Rust stays untouched as reading material.

Baseline at lane start: ga area absent from bt.py, no src/ga, no tests/unit/ga.

## Step 1: red test surface

- Headers: src/ga/inventory.h, features.h, ga.h, hash.h, dist.h, lib.h.
  bt_ga_case_row and bt_ga_pair_count (dist) carry the freq data rows,
  bt_ga_case_count stays a function like Rust inventory CASE_COUNT.
- tests/unit/ga: ga_test_util.h (watchdog thread, scratch dirs, feat
  builders, wordlist helpers), death_test.h (env self-spawn, exit 134),
  features_test.c, features_tables_test.c, inventory_test.c,
  inventory_more_test.c, ga_test.c, ga_public_surface_test.c,
  fuzzkill_ga_test.c, hash_test.c, dist_test.c, lib_test.c.
- 105 tests total across 11 exes: 13 features, 3 features_tables, 14
  inventory, 6 inventory_more, 23 ga, 7 ga_public_surface, 22 fuzzkill_ga,
  2 hash, 2 dist, 1 lib, plus 12 watchdog/death helpers in the suites.
- Red state: every exe compiles, every link fails on undefined bt_ga_*
  symbols. Verified with python bt.py test-unit ga.
