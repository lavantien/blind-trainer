5. restart forced keep: kept = max(1, trunc(inject_fraction * pop)) when diversity restart is enabled, so the incumbent island best survives and per-gen monotonicity holds. model updated to the same rule (s0-s4 constants unchanged, verifying no default drift), new s5 scenario (pop 8, elite 7, flat weights, inject 0.1) pins evals 21 = base 14 + 7 replaced with the monotonicity assert. the adversaries' restart0 probe now reports no rise in 60 seeds.

7. fault coverage: table-driven death battery over all 16 remaining run_ex sites via a BT_FAULT_SITE env var (one child fn, per-site case names and expected messages).
