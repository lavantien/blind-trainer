## Step 1: shared fuzz home and fuzz.seed

- config/config.json gains fuzz.seed 20261012.
- tests/fuzz/fuzz_common.h is the single home for BT_FUZZ_GOLDEN,
  bt_fuzz_seed_from, bt_fuzz_within_bounds, the fuzz_bounds loop, corpus
  replay, generation, and the new fuzz_seed config read plus fuzz_plainloop
  wrapper. classify.h and memo.h keep only their bodies and include the shared
  home, tests/unit/scheme/fuzz_runner.h is deleted.
- All four suites call fuzz_plainloop with LLVMFuzzerTestOneInput so the
  plainloop driver and any future libFuzzer driver run the same entry.
  The bodies keep their early-return bounds check from the Rust port.
- Generated inputs are now written to artifacts/fuzz/<name>.pending before
  each harness call and removed at loop end, so a hard crash leaves the
  offending input on disk in every suite, matching the former scheme runner.
- Seed offsets keep the streams distinct: notation uses fuzz.seed, expand
  uses fuzz.seed + 1, classify and memo use fuzz.seed.
- fuzz_body.h: the artifacts root no longer snprintfs a buffer into itself,
  crash and pending paths share one fuzz dir resolver that creates both
  artifacts and artifacts/fuzz.
- Accepted deltas from the merge: scheme classify and memo generation moved
  from 64 byte uniform draws to the shared 128 byte alphabet-biased draws
  with periodic 4096 byte inputs, and corpus replay now counts against the
  fuzz.runs budget. No committed expectation pins those streams.
- python pins: tests/python/test_bt_fuzz.py checks the fuzz.seed hub key and
  the bt.fuzz_suites filter, which selects stem fuzz_ and excludes fuzzkill.
