## findings

- Mode keys 1 2 3 keep immediate select and save from the closed state and now also open the select at that entry. While open, digits move the cursor and enter commits, mirroring the number field semantics. settings_mode_keys_toggle_the_draft was extended to cover both states.
- The solve review column overflows the 800 px window once the broken pairs list passes roughly 7 lines at the new scale, pushing the phase hint off screen. The behavior is pre-existing at a lower threshold (root 20 overflowed past ~16 lines). view_draw_b.solve_review_hint_draws_clear_of_the_splits_block now builds its scramble with a single R turn override so the short review it always meant to show still fits. Follow-up for the hub: clamp the broken block or anchor the hint inside the content area.
- The algs list capacity at the 800 px window moved from 21 to 13 rows, derived from (800 - 154 - 84) / 42.
- bt_alg_parse frees its out argument before parsing, so callers must hand it an initialized bt_alg. Passing an uninitialized struct crashes the process. tests/unit/scheme/scramble_oracle_test.c initializes first.

## decisions

- rem base root_rem 20 -> 28 in src/app/theme.c, one hub location, every role and spacing scales proportionally (nominal body 28 px, visible band ~16.8 to 21 px).
- settings layout: 3 rows (cadence, mode, reps), centered 26 rem column, 2.6 rem row height, 1 rem gap, label left with hint line under it (font_small muted), control right-aligned 11 rem wide with 0.3 rem vertical inset. Steppers reuse bt_ui_number_field unchanged.
- new additive ui surface: bt_ui_select_state {open, cursor}, pure bt_ui_select_transition, drawing bt_ui_select (collapsed by default, click or digit opens, arrows and digits move the cursor, enter commits, escape or click outside closes, click on an option picks it). bt_ui_input gains int up, int down (additive), filled by bt_app_poll_input in src/app/window.c, 2 lines, same function that already fills enter and escape. This window.c touch is reported here per the surface-edit rule.
- mode rows render as "1 syllables", "2 images", "3 per-orbit" so the digit key is visible on the collapsed face and in the open list.
- mode keys 1 2 3 keep immediate select and additionally open the select at that entry, per the brief. While open, digits move the cursor only and enter commits.
- input_focus now includes select open so escape closes the dropdown instead of leaving the view.
