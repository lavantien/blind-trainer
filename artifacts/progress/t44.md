## decisions

- baselines captures through the L20/L21 machinery unchanged: same bt-e2e driver argv, same artifacts/e2e out dir, same artifacts/e2e-user APPDATA sandbox, bounded by e2e.timeout_secs inside the driver and the 300 s python bound outside.
- the determinism gate hashes in place between the two passes; the driver cleans pngs at capture start and validates the set against config e2e.shots, so a short or extra png set cannot pass silently.
- landing goes through visual-diff.exe `--update` (L11 contract) rather than a python copy, so stale baselines outside the shot set are pruned by the same tool that adjudicates them.
- scoped builds only: `_ensure_visual_diff` builds tools with only visual_diff, never build_suites, so the detached mutation host holding build/bin/mutate.exe is never touched.
- no config.json keys added or changed.
