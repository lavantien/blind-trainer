## decisions

- baselines captures through the L20/L21 machinery unchanged: same bt-e2e driver argv, same artifacts/e2e out dir, same artifacts/e2e-user APPDATA sandbox, bounded by e2e.timeout_secs inside the driver and the 300 s python bound outside.
- the determinism gate hashes in place between the two passes; the driver cleans pngs at capture start and validates the set against config e2e.shots, so a short or extra png set cannot pass silently.
- landing goes through visual-diff.exe `--update` (L11 contract) rather than a python copy, so stale baselines outside the shot set are pruned by the same tool that adjudicates them.
- scoped builds only: `_ensure_visual_diff` builds tools with only visual_diff, never build_suites, so the detached mutation host holding build/bin/mutate.exe is never touched.
- no config.json keys added or changed.

### round B, atomic baseline landing

- btvd_fs_copy now writes `<destination>.tmp` and lands it through the new btvd_fs_replace, MoveFileExW with MOVEFILE_REPLACE_EXISTING on windows and rename elsewhere; every failure path removes the temp file, so a baseline file is either fully the old bytes or fully the new bytes.
- red pin: tests/unit/tools/visual_diff_update_atomic_test.c holds the destination open with FILE_SHARE_READ | FILE_SHARE_WRITE and no FILE_SHARE_DELETE. Under the old direct write the update returned 0 and swapped the held file; under the temp-plus-rename it returns -1, the held file keeps its original bytes, and no .tmp remains. The suite deliberately carries no raylib include so windows.h can sit in the TU.

### round C, selftest config name

- btvd_write_selftest_config and btvd_tolerance_from_config now use `<workdir>/visual-diff-selftest-config.json`, so a direct `visual-diff.exe --selftest .` at the repo root can no longer overwrite the real config/config.json.
- red pin: write_config_never_touches_a_workdir_config_json plants a sentinel config.json, runs the writer, and asserts the sentinel bytes survive and the uniquely named file exists; the round-trip and run_selftest pins moved to the new name with it.
