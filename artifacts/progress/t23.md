## Interface freeze

- geometry.h defines the shared engine interface: bt_pz_engine is a
  struct of function pointers (parse_move, parse_alg, format_alg,
  invert_alg, apply_alg, solved_state, is_solved, facelets) over
  per-engine move and state structs, with move_size and state_size for
  generic allocation.
- bt_pz_alg is the universal alg handle, a growable byte vector keyed
  by the engine move_size. parse functions stage into a fresh vector
  and commit only on success, so a failed parse leaves the caller alg
  untouched, matching the Rust fresh Vec return.
- bt_pz_error carries parse and apply failures with the offending
  token, capped at BT_PZ_TOKEN_MAX. bt_pz_grid is the facelet grid,
  caps 12 faces by 12 rows by 12 cols, covering nxn through 7x7, sq1
  rings, and the 12-face megaminx view.
- bt_pz_alg_default_parse is the shared whitespace tokenizer over an
  engine's parse_move, used by nxn and any token-per-move engine.
- Allocation failure aborts through the trace ring, matching the Rust
  Vec allocation panic.

## Defects the red tests caught before green

- tier1.c and nxn.c first drafts used nested functions, rejected by
  c23, rewritten with a static helper and a goto cleanup path.
- default parse and sq1 scan mutated the caller alg before failing,
  the nxn whitespace test pinned the Rust fresh Vec contract, both
  parsers now stage and commit on success only.
- sq1 inversion canonicalized the turn before negating, sending
  (-5,6) to (5,-6) outside the parse domain, fixed to negate first
  then map -6 to 6, pinned by the inversion domain test.
- the default parser scratch buffer is now max_align_t aligned so
  engine move structs with 4-byte members read legally.
