# data provenance

## ref_ground

ref_ground/ holds TSV dumps converted from two spreadsheet exports of the blddb project (github.com/nbwzx/blddb, GPL-3.0, author Zixing Wang), auto-collected per solver from youtube solve reconstructions by scripts/youtube.py on branch v2. The exports were provided by the repo owner and pinned at dump time:

| source file | sha-256 | retrieval date |
| --- | --- | --- |
| Tommy Cherry's 3BLD algs.xlsx | DE60EFB66F974C123A84004E214D691BA2762B71718A9BF2F764BCA0B33C466A | 2026-10-10 |
| Charlie Eggins's 3BLD algs.xlsx | 3C1BECF9C4ABA50C1945D8513E78F34314B7FDAE767112847ABEDB9F57AA9B68 | 2026-10-10 |

ref_ground/ is gitignored local grounding and is never committed, so the GPL-3.0 origin of the blddb-derived data never enters this repository's history.

## derived data

data/vendor and data/ga are locally generated by make gen-data and make ga. They derive from ref_ground/ plus code in this repo, stay gitignored and local, and regenerate on demand.

## ref_doc

ref_doc/ holds offline reference snapshots fetched by make docs-fetch. It is gitignored local grounding, same policy as ref_ground/.

## regeneration

Run make docs-fetch for the reference snapshots. For the xlsx retrieval and TSV conversion steps see ref_ground/PROVENANCE.md, which pins both workbooks by sha-256, records the retrieval date, and names the conversion script and its run date.
