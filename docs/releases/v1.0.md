# blind trainer v1.0

this release grows the trainer from a 3BLD-only tool into a multi-event algorithm repository where every alg row is mechanically verified, and rebuilds the quality chain around mutation gating.

- multi-event repository: 21 seed packs with 1115 provenance-tagged rows across 3BLD pairs, 3x3 CFOP and OH mirrors, 2x2, big cubes 4x4 to 7x7, square-1, pyraminx, megaminx, skewb, and FTO. one browser cascade, per-case detail with source host and content hash, override CRUD gated at input, and FSRS case drilling for every event.
- puzzle engines: a generic nxn facelet engine for 2x2 through 7x7 with geometric layer moves, plus square-1 with state-aware slash, pyraminx, skewb, megaminx, and FTO with all 8 faces, closing the BR gap the source data carried. every engine passes round-trip and cross-engine oracle suites against the 3x3 model.
- verification tiers: tier 1 parses and applies every row and proves alg plus inverse returns to solved. tier 2 structural stage predicates certify what can honestly be certified per event, from F2L slot disturbance to square-1 cubeshape, and the trust level ships as a badge. the repo gate fails closed on any tier 1 failure, row count drift, or hash drift.
- FSRS-5 scheduling: the SM-2 scheduler is replaced by FSRS-5 with 19 spec-pinned weights and reference vectors, existing review history migrates deterministically, and due state now drives per-event drill sessions.
- SQLite persistence: user data moves into a versioned database with migrations, a backup before every schema change, and a one-time import of the legacy JSON files.
- fingertrick scoring: alg synthesis now ranks by a fingertrick model with regrip and rotation penalties instead of raw move count, cached by a params hash so regeneration only runs when the model changes.
- 3D replay: solved states and algs replay on a real 27-cube model with animated layer turns, drag to orbit, wheel zoom, and a deterministic smoke capture.
- verification chain: zero-comment and constants policy checks with a per file size cap, a mutation gate where every surviving mutant is killed or adjudicated in a reviewed allowlist, a packaged release verifier that boots the shipped zip under scrubbed environment, a memory guard over repo processes, sandboxed e2e with visual baselines and a capture provenance log.

quality gates on this release: 1584 tests, 7 fuzz targets, mutation testing over 3103 mutants with 71 survivors each adjudicated equivalent or hang-only in the gate allowlist, 10 e2e shots with visual regression green on repeated runs.

windows build:

1. download and extract the zip, keep blind-trainer.exe next to the config/ and assets/ folders it ships with.
2. place your ref_ground/ folder next to blind-trainer.exe (the vendor alg sheets and seed packs, see DATA_PROVENANCE.md in the repository for retrieval and conversion steps). without it the app still runs on user data alone and warns at the menu.
3. run blind-trainer.exe. user data persists in %APPDATA%/blind-trainer and migrates legacy JSON files into the database on first run.

source builds from the repository with `python scripts/vendor.py`, `python scripts/fetch_docs.py`, `python bt.py build`, and `python bt.py gen-data`, then the app runs from `build/bin/bt-app.exe`.
