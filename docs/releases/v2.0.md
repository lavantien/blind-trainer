# blind trainer v2.0

this release rebuilds the trainer as a single C23 application, moves every build, test, and release step onto the python `bt.py` driver, and deletes the rust era files from the repository.

- the c23 port: one codebase replaces the rust and bevy workspace, renders through raylib 6.2, and stores every user record in sqlite 3.54.1, both libraries vendored under sha pins. `python bt.py` replaces make as the driver for every build, test, and release step. every binary builds byte-identical, object timestamps are zeroed and the link runs with /brepro.
- native toolchain: bt-mutate mutates the c sources against their suites with a resumable ledger and scratch trees that clean up when a run dies, and mutants-gate fails unless every survivor matches a justified allowlist row, stale rows also fail. the 7 fuzz suites run in plainloop mode, no libFuzzer driver needed. the 10 visual baselines are accepted only when 2 smoke captures match byte for byte, and the provenance file records the capture recipe. release-verify byte-checks the dist zip and boots the packaged exe under a scrubbed environment. the memory guard watches repo processes, and the policy scans enforce zero comments, the constants hub, and the sloc cap.
- feature surface: every event engine carries over, nxn from 2x2 to 7x7, square-1, pyraminx, megaminx, skewb, and FTO, with the 2 tier pack verification on every row. FSRS-5 schedules every drill, the 3d replay animates your solve with orbit and zoom, and the genetic syllable optimizer gains an optional CUDA evaluation flavor: the plain build never invokes nvcc, and ga-parity compares the cpu and cuda flavors on a fixed seed, pins the ranking, and reports which lane ran.
- the interface: typography scales from the window height through one rem root, the menu is a centered 2 column grid, detail text centers with recon links that open in the system browser, the net sticker grid sits symmetric inside its face plate, and a shared fitting helper ends text with an ellipsis when its column is too narrow, down to the smallest windows.
- rust removal: the rust workspace, the makefile, and the rust era probe programs are deleted, the repository is C23, python, and data.

quality gates on this release: 1968 c test cases across 191 suites plus 276 python tests, all green under `python bt.py test`, 7 fuzz suites green in plainloop mode, mutation testing over 24345 generated mutants, 3136 unviable, 14984 caught by the suites, and 6225 survivors every one adjudicated in the gate allowlist, 10 e2e shots against baselines captured from byte-identical double captures.

windows build:

1. download and extract the zip, keep blind-trainer.exe next to the config/ and assets/ folders it ships with.
2. copy the ref_ground/ folder from a repository clone next to blind-trainer.exe (the vendor alg sheets and seed packs, DATA_PROVENANCE.md records their sources and sha pins). without it the app still runs on user data alone and warns at the menu.
3. run blind-trainer.exe. user data persists in %APPDATA%/blind-trainer, the numbered migrations run on first launch, and legacy JSON files import once.

source builds from the repository with the LLVM 23 toolchain on PATH, then `python scripts/vendor.py`, `python scripts/fetch_docs.py`, `python bt.py build`, and `python bt.py gen-data`, and the app runs from `build/bin/bt-app.exe`.
