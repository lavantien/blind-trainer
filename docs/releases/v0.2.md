# blind trainer v0.2

this release makes the cube net read like a real cube and extends the alg library to near-full pair coverage.

- cube net: every face plate has a framed outline, stickers carry stroke ink matched to their fill, and the U and D faces sit over the F column. screenshots and visual baselines regenerated.
- generated algs: a commutator synthesis engine covers 3-style pairs the vendor sheets miss. 817 of 818 pairs carry at least one verified alg (99.9%), each cross-checked against the reference simulator and the shared verify path. the single uncovered pair is recorded in the manifest.
- decomposition fix: the interchange order is picked per unit instead of globally, so combo algs with mixed orders verify correctly.
- verification fix: simcheck agreement is counted over matched rows only, and unnamed-residue claims are rejected instead of half-accepted.

quality gates on this release: 814 tests across 72 suites, 4 fuzz targets, mutation testing with every survivor killed or proven equivalent, e2e and visual regression suites, workspace coverage at 92.4% regions.

windows build:

1. download and extract the zip, keep blind-trainer.exe next to the config/ and assets/ folders it ships with.
2. place your ref_ground/ folder next to blind-trainer.exe (the vendor alg sheets reconstructed from blddb exports, see DATA_PROVENANCE.md in the repository for retrieval and conversion steps). without it the app still runs on user data alone and warns at the menu.
3. run blind-trainer.exe. user data persists in %APPDATA%/blind-trainer.

source builds from the repository with make gen-data && make run.
